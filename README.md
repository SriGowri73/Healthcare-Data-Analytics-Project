# Healthcare Data Analytics Project

## Overview
This project explores a healthcare dataset using Python to identify patterns, trends, and relationships in patient demographics, medical conditions, hospital admissions, and billing information.

## Objective
To perform data cleaning, preprocessing, exploratory data analysis (EDA), and data visualization to extract meaningful insights from healthcare data.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Workflow
1. Loaded and inspected the healthcare dataset.
2. Examined missing values, duplicate records, and data types.
3. Cleaned and preprocessed the dataset.
4. Performed exploratory data analysis using descriptive statistics and grouping.
5. Created visualizations to examine medical conditions, patient age distribution, and billing patterns.
6. Exported the cleaned dataset and summary results.
